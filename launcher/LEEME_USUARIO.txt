==============================================================
  SOÑAR DESPIERTO — SISTEMA DE GESTIÓN
  Guía rápida para el personal
==============================================================

¿QUÉ ES?
--------
Es el programa de la asociación para organizar voluntarios, niños,
escuelas, tutores, cartas de Navidad, calendario e inventario.
Funciona en esta computadora y no necesita internet.


CÓMO ABRIRLO
------------
1. Haz doble clic en el ícono "Soñar Despierto" del Escritorio
   (o en SonarDespierto.exe dentro de esta carpeta).
2. Se abre una ventana negra y, unos segundos después, el
   navegador con la pantalla para iniciar sesión.

   Si el navegador no se abre solo, escribe en la barra de
   direcciones la dirección que aparece en la ventana negra
   (normalmente http://localhost:8765).


LA PRIMERA VEZ
--------------
- La ventana negra muestra el correo y una contraseña temporal
  del administrador. También quedan guardados en el archivo
  CREDENCIALES_INICIALES.txt de la carpeta de datos (ver abajo).
- Al entrar, el sistema te pedirá cambiar esa contraseña por
  una propia (al menos 8 caracteres, con letras y números).
- Cuando la cambies, el archivo de credenciales se borra solo.


¡NO CIERRES LA VENTANA NEGRA!
-----------------------------
Mientras la ventana negra esté abierta, el sistema funciona.
Si la cierras, el sistema se apaga (tus datos NO se pierden).
Para volver a usarlo, haz doble clic otra vez en el ícono.

Si haces doble clic con el sistema ya abierto, solo se abre
otra pestaña del navegador.


ENTRAR DESDE OTRAS COMPUTADORAS DE LA OFICINA
---------------------------------------------
1. Cierra el sistema (cierra la ventana negra).
2. Abre la carpeta de datos (ver abajo) y edita el archivo
   config.env con el Bloc de notas. Cambia:
       LAN_MODE=false
   por:
       LAN_MODE=true
   y guarda el archivo.
3. Abre el sistema de nuevo. Si Windows pregunta por el
   Firewall, marca "Redes privadas" y acepta.
4. En las otras computadoras, escribe en el navegador la
   dirección que muestra la ventana negra en
   "Desde otras PCs de la red" (por ejemplo
   http://192.168.1.25:8765).

IMPORTANTE: usa el modo de red solo en la red de la oficina.
NUNCA lo actives en redes Wi-Fi públicas (cafeterías, plazas,
hoteles, etc.).


SI OLVIDAN LA CONTRASEÑA DEL ADMINISTRADOR
------------------------------------------
1. Cierra el sistema (cierra la ventana negra).
2. Abre la carpeta del programa (donde está SonarDespierto.exe).
3. Haz clic en la barra de direcciones de la carpeta, escribe
   cmd y presiona Enter.
4. En la ventana que se abre, escribe:
       SonarDespierto.exe --reset-admin
   y presiona Enter.
5. Aparecerá una contraseña temporal nueva. Úsala para entrar;
   el sistema te pedirá cambiarla.


¿DÓNDE ESTÁN LOS DATOS?
-----------------------
En la carpeta:
    %LOCALAPPDATA%\SonarDespierto
(cópiala y pégala en la barra de direcciones del Explorador).

Ahí están la base de datos, la configuración (config.env), el
registro de actividad (logs) y los respaldos.

NO BORRES NI MUEVAS ESA CARPETA: ahí está toda la información
del sistema. No la pongas dentro de OneDrive, Dropbox ni otra
carpeta sincronizada.
